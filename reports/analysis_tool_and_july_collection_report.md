# 분석 도구 선택 및 2026년 7월 게시물 추가 수집 리포트

## 1. 구현 요약
- 관리자 페이지에 분석 도구 선택 UI를 추가했습니다.
  - `Gemini`
  - `ChatGPT`
- 선택값은 `runtime_settings.json`에 저장되며, 이후 신규 분석부터 적용됩니다.
- 기존 분석 데이터는 다시 분석하지 않도록 원본 파일 SHA-256 해시 기반 중복 스킵을 추가했습니다.
- `CHATGPT_API_KEY`, `CHATGPT_MODEL` 환경변수 자리를 추가했습니다.
- ChatGPT 선택 시 내부적으로 ChatGPT API 키가 필요하며, 키가 없으면 분석 시 명확한 예외가 발생합니다.
- 2026년 7월 게시물 후보를 추가 수집했습니다.

## 2. 수집 결과
- 기존 분석 데이터: 5건 유지
- 추가 수집 실행 결과:
  - 다운로드 후보: 10건
  - 기존 중복 스킵: 5건
  - 신규 AI 분석 저장: 4건
  - HWP 파싱 실패 원본 보존: 1건
- 현재 DB 상태:
  - `raw_documents`: 10건
  - `asset_events`: 10건
  - `ai_analyses`: 9건

## 3. 표시 상태
- 사용자 페이지와 관리자 페이지 모두 2026년 7월 게시물 10건을 표시합니다.
- HWP 파싱 실패 건은 `PARSE_FAILED` 상태로 원본과 이벤트를 보존합니다.
- 관리자 페이지에서 분석 도구 선택값 저장을 검증했습니다.
  - `chatgpt` 저장 확인
  - 다시 `gemini`로 복구 확인

## 4. ChatGPT 사용을 위해 필요한 정보
- `CHATGPT_API_KEY`: ChatGPT/OpenAI API 호출용 키
- `CHATGPT_MODEL`: 기본값 `gpt-5.5`
- 관리자 페이지에서 `ChatGPT` 선택

## 5. 주의 사항
- ChatGPT 웹앱 구독 또는 Codex 유료 결제는 이 백엔드의 자동 API 호출 권한으로 바로 연결되지 않습니다.
- 자동 분석 파이프라인에서 ChatGPT를 쓰려면 API 키가 필요합니다.
- 현재 기본 분석 도구는 안정성을 위해 `Gemini`로 되돌려 두었습니다.
