# 경·공매 소거형 검토 보조 플랫폼  
## 최종 통합 마스터 기획서 v13.1  
### 무료 기반 정보 플랫폼 / 소거형 UX / 원문 확인 중심 / 보수적 확장 전략

작성 목적: 본 문서는 v10.1, v12.1, v13.0 초안을 통합 검토하여 만든 최종 기획 기준서다.  
문서 성격: 순수 기획·BM·IA·UX·GTM·장기 확장 방향 문서이며, 코드·DB·API 구현 지시서는 아니다.  
최종 원칙: 서비스는 투자 판단을 대신하지 않는다. 사용자가 경·공매 후보를 빠르게 줄이고, 남긴 후보를 원문 중심으로 검토하도록 돕는다.

## 0. v13.0 초안 검토 결론

v13.0 초안은 v10.1과 v12.1의 보수적 원칙을 비교적 잘 흡수했다. 특히 “오늘 검토 완료”, “오류 제보”, “검토 공유용 요약”, “Development Insight Track”을 실제 제품 단위로 내린 점은 채택 가치가 있다.

다만 일부 표현은 여전히 조정이 필요하다.

### 0.1 수정해야 할 표현

| 초안 표현 | 문제 가능성 | 최종 권장 표현 |
|---|---|---|
| 법적 안전성 | 법률 리스크가 완전히 제거된 듯한 인상 | 법률 자문으로 오인될 가능성 최소화 |

| 런칭 6개월~1년 이후 | 일정 확정처럼 보임 | 핵심 지표 충족 후 별도 트랙으로 검토 |

- 오류 제보는 자유 입력을 최소화하되, 운영팀 내부 확인용 짧은 보충 입력은 개인정보 차단 안내와 함께 제한적으로 검토할 수 있다.

## 1. 최종 서비스 정체성

이 서비스는 경·공매 투자 판단 플랫폼이 아니다.

최종 정체성은 다음이다.

> 매일 새로 나온 경·공매 후보를 빠르게 훑고, 관심·패스·메모·원문 확인 포인트로 내 검토 흐름을 관리하는 무료 기반 정보 플랫폼

최종 핵심 문장:

> 우리는 경·공매 투자 판단 플랫폼이 아니라, 경·공매 후보를 빠르게 거르고 기록하게 만드는 무료 기반 검토 보조 플랫폼이다.

서비스가 제공하는 것:

- 오늘 볼 후보 제시
- 패스 기반 검토 목록 정리
- 관심·감시·메모 관리
- 자료 완결성 표시
- 원문 확인 포인트 정리
- 원문 확인 유도
- 검토 공유용 요약
- 제한적 오류 제보
- 반복 방문 검토 루틴 지원

서비스가 제공하지 않는 것:

- 투자 추천
- 권리분석
- 안전성 판단
- 위험성 판단
- 수익성 판단
- 입찰 가능 여부 판단
- 예상 낙찰가
- 명도 가능성 판단
- 전문가 검증
- 상담 결과 보증
- 개발 수익성 보장

허용:

> 현재 정리된 정보만으로는 권리관계 판단을 제공하지 않습니다. 원문과 관계 서류를 직접 확인하세요.

## 3.3 오늘 검토 완료 시스템

### 3.3.1 정의

오늘 신규 후보 목록에서 사용자가 모든 후보를 패스 또는 관심으로 분류하여 남은 후보가 0건이 되었을 때 표시하는 완료 상태다.

이는 게임화나 중독 설계가 아니다.  
검토 피로를 줄이고 사용자가 오늘의 정리 상태를 인지하도록 돕는 UX다.

### 3.3.2 완료 조건

- 오늘 신규 후보 목록에 진입했다.
- 사용자가 각 후보에 대해 패스 또는 관심을 선택했다.
- 처리되지 않은 오늘 신규 후보가 0건이 되었다.

### 3.3.3 완료 화면 문구

> 오늘 새로 확인할 후보를 모두 정리했습니다. 관심 물건과 감시 중인 물건은 내 검토함에서 다시 확인할 수 있습니다.

### 3.3.4 완료 요약

평가 없이 숫자만 보여준다.

예시:

> 오늘 신규 후보 24건 중 20건을 패스하고 4건을 관심으로 남겼습니다.

금지:

- 오늘의 투자 검토를 완벽하게 완료했습니다.
- 좋은 물건을 모두 찾았습니다.
- 내일 새로운 기회를 잡으세요.
- 투자 안목이 뛰어납니다.

- 패스: 기본 목록에서 숨긴 후보

## 4. 자료 완결성 배지

자료 완결성 배지는 투자 안전성이 아니다.  
수집된 자료의 상태와 원문 확인 필요성을 나타낸다.

허용 배지:

- 핵심 정보 확인됨
- 가격 확인 필요
- 일정 확인 필요
- 원문 확인 필요
- 위치 확인 필요
- 면적 확인 필요
- 자료 일부 부족
- 종료됨

금지 배지:

- 안전
- 위험
- 추천
- 알짜
- 저평가
- 수익 기대
- 명도 쉬움

배지 설명 문구:

> 이 배지는 투자 판단이 아니라 자료 완결성 상태를 나타냅니다. 최종 판단 전 원문과 관계 서류를 직접 확인해야 합니다.

## 5. 자료 확인 필요 탭

자료 부족은 기회가 아니다.  
자료 부족은 확인해야 할 정보가 부족한 상태다.

탭 명칭:

> 자료 확인 필요

탭 설명:

> 일부 정보가 충분하지 않아 원문 확인이 필요한 후보입니다. 가격, 일정, 위치, 면적 등 주요 항목을 원문에서 직접 확인하세요.

금지 표현:

- 숨겨진 보물
- 고수들이 보는 물건
- 경쟁이 낮은 물건
- 초보자가 놓치는 기회
- 수익 가능성이 있는 물건

## 6. 오류 제보 / 자료 보완 요청

### 6.1 목적

공공 데이터와 수집 자료에는 누락이나 오류가 있을 수 있다.  
오류 제보 기능은 사용자 참여형 커뮤니티가 아니라 제한적 자료 보완 창구다.

기능명:

> 오류 제보 / 자료 보완 요청

### 6.2 초기 제보 항목

객관식 체크박스 중심으로 운영한다.

- 가격 정보 오류 의심
- 일정 정보 오류 의심
- 원문 링크 접속 불가
- 사진/주소 불일치 의심
- 위치 정보 오류 의심
- 면적 정보 오류 의심
- 종료 상태 오류 의심
- 중복 물건 의심
- 개인정보 노출 의심

### 6.3 운영 원칙

- 제보 내용은 즉시 공개하지 않는다.
- 운영팀 검토 전에는 공개 화면에 반영하지 않는다.
- 자유 입력은 최소화한다.
- 자유 입력이 있을 경우 개인정보 입력 금지 안내를 둔다.
- 제보자는 법률 판단이나 투자 의견을 남기도록 유도하지 않는다.

접수 문구:

> 제보가 접수되었습니다. 자료 상태 확인을 위해 운영팀 검토가 필요할 수 있습니다. 제보 내용은 확인 전까지 공개 정보로 반영되지 않습니다.

## 12. Development Insight Track

### 12.1 정의

Development Insight Track은 초기 핵심 서비스가 아니다.  
장기적으로 토지·건물 후보에 대해 개발 가능성 관련 기초 확인 항목을 정리하고, 사용자가 입력한 가정에 따른 비용·공간 검토를 돕는 별도 확장 기능이다.

초기 핵심 서비스:

> 오늘 볼 경·공매 후보를 보여주고, 안 볼 물건을 패스하게 하며, 남은 물건을 원문 중심으로 검토하게 하는 것.

Development Insight Track:

> 토지·건물 후보에 대해 개발 가능성 관련 기초 확인 항목을 정리하고, 사용자가 입력한 가정에 따른 비용·공간 검토를 돕는 별도 확장 기능.

### 12.2 Archi-Pro 연계 포지셔닝

Archi-Pro 연계는 “돈을 얼마나 벌 수 있는지 알려주는 기능”이 아니다.  
“대상 토지나 건물에 어떤 물리적 검토가 필요한지 이해하는 스케치북”에 가깝다.

권장 포지셔닝:

> 내가 검토 중인 토지·건물 후보에 대해 용도지역, 대지면적, 건폐율·용적률 등 기초 정보를 바탕으로 대략적인 공간 검토를 해보는 참고 도구

금지 표현:

- 이 땅에 신축하면 얼마를 벌까
- 수익성 확인
- 개발 수익 계산
- 권리상 문제가 없음을 AI로 확인
- 낙찰 후 가치 상승 가능
- 돈 되는 개발 후보

권장 표현:

- 개발 가능성 기초 검토
- 용도지역 확인
- 건폐율·용적률 기초 확인
- 가정 기반 개발비 계산
- 대략적 공간 검토
- 참고용 3D 매스 검토

### 12.3 진입 위치

초기에는 홈 전면에 노출하지 않는다.

권장 위치:

- 상세 화면 하단 보조 영역
- 내 검토함의 선택 기능
- 토지·단독주택·상가주택 유형에서만 제한 노출

권장 버튼명:

> 개발 가능성 기초 검토

면책 문구:

> 가정 기반 개발비 및 대략적 공간 검토를 돕는 참고 기능입니다. 실제 건축 인허가, 사업성, 수익성, 법률 판단을 보장하지 않습니다.

고정 일정이 아니라 지표 기반으로 검토한다.

## 13. 현재 개발 상태 반영 메모

첨부된 v006-a3 결과 기준, 현재 서비스는 공개 `/onbid` QA용 데이터셋을 일정 규모 확보한 상태다.

반영해야 할 사실:

- public-visible fresh non-sample 총 100건 확보
- 부동산 60건, 동산 40건 확보
- 최종 DB 총 188건, fresh 107건, stale 61건, invalid_date 20건, unknown_date 0건
- `/onbid`, `/onbid?category=real_estate`, `/onbid?category=movable` 공개 QA 통과
- 비로그인 상세에서 관심/감시/패스/메모 form 미노출
- 비로그인 상세에서 로그인 CTA 노출
- raw AI 분석 본문 공개 노출 없음
- `repair_onbid_derived_fields.ps1 -Apply`는 실행하지 않았고, 현재 기준 권장하지 않음
- 동산 상세 marker가 적어 상세 품질 보강 여지가 있음
- 다음 devpack 후보는 public `/onbid` 필터·정렬·상세 UX 개선, 운영 스케줄러 리허설, 공고목록·국유재산 API 검증

이 상태를 기준으로 다음 개발은 “데이터 확보”보다 “공개 UX 품질, 안전한 문구, 검토 루틴, 이벤트 계측”에 집중하는 것이 적절하다.
